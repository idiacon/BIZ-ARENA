# Biz Arena v0.3 Sprint 9 - Unified Defense Bundle

## Goal

Create a single reproducible command that assembles the defense transfer package into one ZIP file.

## Implemented Scope

- Added `scripts/build-defense-bundle.js`.
- Added npm script:

```powershell
npm run release:defense-bundle
```

- Bundle staging root:

```text
dist/defense-bundle/Biz-Arena-v0.3.0/
```

- Final generated archive:

```text
dist/Biz-Arena-v0.3.0-defense-bundle.zip
```

## What The Bundle Includes

- Core docs for defense (`README`, demo script, checklists, Q&A, roadmap, sprint notes).
- Presentation-support docs (outline, slide text, screenshot map).
- Report materials (`docs/report-draft.md`, generated DOCX draft).
- Generated screenshots in `defense-assets/screenshots/`.
- Demo results JSON in `defense-assets/results/`.
- Fallback desktop package:
  - `dist/Biz-Arena-0.3.0-win-unpacked.zip`
  - `dist/release-manifest-0.3.0.json`
- Any `dist/*.exe` files that contain the current version `0.3.0`.

## Output Manifest

The script writes:

```text
dist/defense-bundle/Biz-Arena-v0.3.0/bundle-manifest.json
```

This records included files and generated artifacts so the package is auditable before submission.

## Why This Matters

Before Sprint 9, the release files were correct but collected from many places manually. Sprint 9 makes the handoff deterministic: one command produces one transfer ZIP with the needed defense materials.
