# Biz Arena v1.0 Beta: Local Classroom handoff

## Что запускать

Передайте преподавателю `BizArena-Classroom-1.0.0-beta.1.zip`.

Внутри архива:

- `BizArena-Server-1.0.0-beta.1-Portable-x64.exe` - основной запуск на ПК преподавателя без установки;
- `BizArena-Server-1.0.0-beta.1-Setup-x64.exe` - установщик сервера преподавателя;
- `BizArena-Client-1.0.0-beta.1-Portable-x64.exe` - запуск на ПК ученика без установки;
- `BizArena-Client-1.0.0-beta.1-Setup-x64.exe` - установщик клиента ученика;
- `tools/Allow-BizArena-Firewall.bat` - открыть Windows Firewall для Biz Arena;
- `tools/Check-BizArena-LAN.bat` - проверить подключение с ученического ПК;
- `README-classroom.md` - краткая инструкция внутри архива.

## Быстрый запуск

1. На ПК преподавателя открыть `BizArena Server`.
2. В стартовом экране `/server` создать комнату и оставить включённым `Показывать во вкладке «Подключиться»`, если занятие должно появиться в списке учеников.
3. Показать ученикам:
   - код комнаты;
   - LAN ссылку вида `http://192.168.x.x:3000/client`;
   - QR из блока Network Doctor.
4. Ученики открывают `BizArena Client` или обычный браузер по LAN ссылке.
5. Во вкладке `Доступные занятия` ученики выбирают нужное лобби, затем вводят пятисимвольный код, имя и название команды. Код в публичном списке не показывается.
6. Если список недоступен, используйте вкладку `Ввести код` или QR-ссылку — старый путь сохранён.
7. После входа ученики нажимают `Готов`.
8. Преподаватель запускает матч и управляет темпом из вкладки `Преподаватель`.

## Управление матчем

- `Пауза` останавливает общий таймер и расчёт для всего класса.
- После обновления страницы или повторного открытия `/server` paused-матч остаётся доступен во вкладке `Преподаватель`.
- `Продолжить` возвращает матч в рабочую фазу.
- `Следующий ход` выполняет серверный пересчёт и переводит класс на следующий ход.
- `Завершить игру` фиксирует победителя и открывает итоговый разбор.

После завершения преподаватель видит class debrief, вопросы для обсуждения и JSON-отчёт занятия. Ученики видят только собственный разбор и общие игровые итоги, без преподавательской методички.

## Firewall

1. Если ученики не видят сервер, запустите `tools/Allow-BizArena-Firewall.bat` от имени администратора.
2. Разрешите частные сети, если Windows покажет системный запрос.
3. С ученического ПК откройте:

```text
http://IP-ПРЕПОДАВАТЕЛЯ:3000/api/health
```

Нормальный ответ содержит `"ok": true`.

## Где взять QR и LAN ссылку

На экране `/server` есть Network Doctor:

- `LAN ссылка` - адрес для учеников в общей сети;
- `QR` - быстрый вход на `/client`;
- `/api/health` - проверка, что сервер доступен.

Если `127.0.0.1` открывается только у преподавателя, это нормально: ученикам нужен LAN IP вида `192.168.x.x`, `10.x.x.x` или `172.16-31.x.x`.

## Если LAN не работает

1. Проверьте `/api/health` с ученического ПК.
2. Проверьте firewall.
3. Убедитесь, что все устройства в одной подсети.
4. Если вузовская сеть блокирует соединения между клиентами, используйте отдельный роутер или точку доступа.
5. Для публичной ссылки используйте развёрнутый KAI/VPS Server; quick tunnel не поддерживается.
