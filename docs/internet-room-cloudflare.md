# Legacy Internet Room Tunnel

This document is kept only as an archive of the old v0.4 experiment.

The tunnel flow is not a supported classroom path in Biz Arena v0.5. Do not use it for teacher handoff, defense demo, or beta release instructions.

Use one of the supported modes instead:

- Local Classroom: `BizArena Server` on the teacher PC, students connect by LAN link or QR.
- Cloud Classroom: public Biz Arena URL with teacher login, cloud room, student link, and QR.

The legacy script is disabled by default. It requires an explicit developer-only environment flag and is not included in the classroom release package.
