# Biz Arena v0.3 Sprint 2 - Defense Polish

## Goal

Make the demo path easier to explain during the June defense without changing the game rules.

## Completed Scope

- Main hero copy now describes the simulator as an educational business tool.
- The first screen includes a short defense-demo note.
- The About screen explains the project, current build, game cycle, KAI championship flow, learning focus, delivery package, author, and organization.
- Defense-facing terminology is friendlier:
  - `tick` -> turn / turn resolution / ход / пересчёт
  - `Intel` -> advisor / советник
  - `pivot preview` -> strategy shift / смена стратегии
  - `execution queue` -> action queue / очередь действий
- Russian, English, and Tatar translation overrides are preserved for the changed surfaces.

## Verification

Run:

```powershell
npm run check
npm test
```

Then open the app and verify:

- hero text mentions education, contracts, turn resolution, and rating;
- `Демо-матч для показа` still starts `KAI Demo Championship`;
- About screen is readable in Russian, English, and Tatar;
- game tabs still render after a demo match starts.
