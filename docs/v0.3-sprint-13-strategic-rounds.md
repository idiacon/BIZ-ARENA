# Biz Arena v0.3 Sprint 13 - Strategic Decision Rounds

## Goal

Add the first Simformer-like strategic dilemma layer to the live match flow, focused on the defense scenario.

## Scope

- Scenario: `motorcycles` only (v1).
- Players: human, non-bankrupt, running match only.
- One active round per player.
- If the player does not choose before the next turn, the system applies the default safe option automatically.

## What Was Added

- Strategic decision-round model per player:
  - `decisionRound` (pending/resolved/auto_resolved),
  - `decisionHistory` (last 3 resolved rounds).
- Fixed dilemma templates for the motorcycle plant:
  - supplier window,
  - workforce policy,
  - maintenance window,
  - dealer campaign.
- New action on existing `/api/action`:
  - `resolve-decision-round` with `{ roundId, optionKey }`.
- Lifecycle in factory turn loop:
  1. auto-resolve expired pending rounds with default safe option,
  2. create new pending rounds by schedule (every 2 days) when possible.
- UI card in Operations (factory flow):
  - shows title/description/expiry,
  - 2-3 options with visible consequences,
  - auto-safe resolution notice from history.

## Notes

- No new API endpoints were introduced.
- This sprint keeps motorcycles-first scope to maximize reliability for June defense and preserve implementation speed.
