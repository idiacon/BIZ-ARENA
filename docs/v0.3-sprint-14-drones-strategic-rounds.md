# Biz Arena v0.3 Sprint 14 - Strategic Rounds Expansion (Drones)

## Goal

Expand the strategic decision-round system beyond motorcycles so the Simformer-like management layer works in more than one factory scenario.

## Scope

- Adds strategic rounds to the `drones` scenario.
- Keeps the same action contract: `POST /api/action` with `action: "resolve-decision-round"`.
- Keeps the same auto-safe behavior:
  - pending round is auto-resolved on the next turn with the default option if the player does not choose manually.

## Drones Templates (v1)

1. `battery_supply`
2. `firmware_release`
3. `airspace_compliance`
4. `payload_strategy`

Each template has:

- title and description keys for UI i18n,
- 3 options (including one safe default),
- explicit effects for player metrics (`money`, `debt`, `reputation`, `quality`, `automation`, `supplyLevel`) and optional factory fields (`inventory`, `finishedGoods`).

## Lifecycle Rules

- Only in supported factory scenarios (`motorcycles`, `drones`).
- Only for active human players (not bots, not bankrupt).
- One pending round at a time per player.
- No round creation in non-running states (`lobby`, `paused`, `finished`).

## Verification

- `npm run check`
- `npm test`
- Integration tests verify:
  - motorcycles behavior remains stable,
  - drones creates pending rounds,
  - drones rounds can be resolved through existing action flow.
