## Current Packaging Status

`npm run dist:win` currently fails in this Windows session while extracting `winCodeSign`:

```text
Cannot create symbolic link
```

This happens before NSIS/portable finalization and is caused by the local Windows symlink privilege, not by Biz Arena source code. The build still produces a fresh `dist/win-unpacked` folder before the final packaging step fails.

## Defense Fallback

If the final installer or portable single-file `.exe` is not available yet, copy this file to the flash drive:

```text
dist/Biz-Arena-0.3.0-win-unpacked.zip
```

Then extract it and launch:

```text
win-unpacked/Biz Arena.exe
```

This is less polished than a single portable `.exe`, but it is a valid desktop build fallback for a live demo.

## How To Finish The Official `.exe`

1. Enable Windows Developer Mode, or use a Windows account/session with the `Create symbolic links` privilege.
2. Open a new PowerShell window.
3. Run:

```powershell
npm run dist:win
```

4. Confirm the final `Biz-Arena-0.3.0-*.exe` artifacts appear in `dist/`.
5. Launch the portable `.exe` and run the KAI demo match once.
