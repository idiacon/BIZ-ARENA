# Biz Arena v0.3 Sprint 15 - Teacher Control For Strategic Rounds

## Goal

Give the host a reliable defense control to show strategic dilemmas on demand without waiting for scheduled turn timing.

## Implemented

- Added host-only action in existing `/api/action` flow:
  - `action: "force-decision-round"`
  - optional `value.targetPlayerId` (defaults to current host player).
- Works in supported factory scenarios with strategic rounds:
  - `motorcycles`
  - `drones`
- Validation:
  - room must be `running`,
  - actor must be host,
  - target must be human and not bankrupt,
  - target must not already have a pending round.
- UI:
  - Operations -> Strategic decision card now shows host-only button:
    - `Запустить демо-дилемму` / `Trigger demo dilemma`
  - enables instant strategic round creation for live demo.

## Why It Matters For Defense

- Removes timing risk during presentation.
- Lets teacher/demo host show dilemma -> choice -> consequence sequence exactly when needed.
- Keeps previous auto-safe behavior unchanged for normal turn flow.

## Verification

- `npm run check`
- `npm test`
- Added integration tests:
  1. host can force a strategic round before scheduled day,
  2. non-host cannot force a strategic round.
