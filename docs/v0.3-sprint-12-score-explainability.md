# Biz Arena v0.3 Sprint 12 - Score Explainability

## Goal

Make the Simformer-like ranking explainable during a live defense: not only show total score, but also show which factors formed it.

## Implemented

- Added a new UI block `Simulation score` in **Statistics**:
  - appears for both factory and non-factory flows;
  - shows component-by-component contribution and total score.
- Added the same `Simulation score` breakdown block in **Results**:
  - available in the final screen after match end;
  - helps explain why the winner is first and why the local player got current rank.
- Added new translation keys for score breakdown labels (ru/en/tt dictionaries are wired).
- Added styling for positive/negative score components and stable numeric rendering.

## Score Components Shown

- Business value
- Liquidity
- Contracts
- Innovation
- Execution
- Profit discipline
- Debt pressure (shown as a negative component)
- Total score

## Defense Value

- The instructor can immediately see that ranking is model-based, not arbitrary.
- Q&A becomes simpler: each score factor has a visible line item.
- The same logic remains consistent between live game view and final results.
