# Biz Arena v0.1 — local test and GitHub checklist

For the first stabilization cycle after Milestone 11, see `docs/v0.1-stabilization-phase-1.md`.
For the follow-up hardening/test-coverage cycle, see `docs/v0.1-stabilization-phase-2.md`.
For the persistence/runtime hardening cycle, see `docs/v0.1-stabilization-phase-3.md`.
For the final release-readiness cycle, see `docs/v0.1-stabilization-phase-4.md`.

## 1. Install dependencies

```bash
npm install
```

If Electron installation is blocked in your environment, fall back to the browser workflow from step 4.

## 2. Run static checks and tests

```bash
npm run check
npm test
```

Expected result:
- syntax checks pass;
- `tests/game-rules.test.js` passes;
- `tests/server-refactor.test.js` passes.

## 3. Launch the desktop app

```bash
npm run desktop
```

Check that:
- the Electron window opens;
- the Play menu shows the `Biz Arena v0.1` host panel;
- local URLs are visible;
- LAN URLs are visible if the machine is connected to Wi-Fi/LAN.

## 4. Fallback browser run

```bash
npm start
```

Open manually:

```text
http://localhost:3000
```

Use this path if Electron cannot start or if you want to isolate shell issues from web/server issues.

## 5. LAN smoke test

1. Start the host machine with `npm run desktop` or `npm start`.
2. Open one of the LAN URLs shown in the v0.1 panel on another device in the same network.
3. Create a room on the host.
4. Join the room from the second device.
5. Start a match and confirm both clients update correctly.

## 6. Pre-publish Git review

```bash
git status
git log --oneline -5
```

Optional final review:

```bash
git diff --stat origin/main...HEAD
```

## 7. Push to GitHub

### If the repository already has a remote

```bash
git push origin work
```

### If you are creating a brand new GitHub repository

```bash
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin work
```

## 8. Optional v0.1 tag

```bash
git tag -a v0.1.0 -m "Biz Arena v0.1"
git push origin v0.1.0
```

```text
Biz Arena v0.1 — LAN prototype with desktop shell
```
