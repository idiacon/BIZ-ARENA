# Чеклист итогового отчёта

Черновик отчёта генерируется в файл:

```text
defense-assets/report/Biz-Arena-report-draft.docx
```

Повторная генерация:

```powershell
npm run report:docx
```

## Обязательная ручная доработка

- Открыть `.docx` в Word или LibreOffice.
- Добавить титульный лист по требованиям преподавателя.
- Проверить ФИО автора: `Надров Дамир Ильнурович`.
- Проверить организацию: `Альметьевский филиал КНИТУ-КАИ`.
- Проверить нумерацию страниц.
- Обновить оглавление.
- Привести шрифт, поля, межстрочный интервал и заголовки к методическим требованиям.
- При необходимости заменить черновые названия разделов на формулировки преподавателя.

## Скриншоты для вставки

Использовать файлы из:

```text

```

## Финальный экспорт

- Сохранить итоговую версию в `.docx`.
- Экспортировать `.pdf`.
- Положить оба файла в финальный пакет для сдачи.

## Примечание по окружению

`.docx` создается без Microsoft Word automation, потому что Word COM недоступен в текущем окружении. Файл формируется как OpenXML-документ и должен корректно открываться в Microsoft Word или LibreOffice для финальной правки.
