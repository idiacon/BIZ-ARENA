# Biz Arena v0.3 Sprint 11 - Simformer Core Step

## Goal

Move Biz Arena toward a true Simformer-like classroom simulator by upgrading ranking logic from net-worth-only to a transparent multi-factor management score.

## Implemented Scope

- Added `buildSimulationScore()` in:
  - `server/game-rules.js`
- Extended player payloads with `simulationScore`:
  - total score
  - component breakdown
- Updated room leaderboard ordering:
  - primary: `simulationScore.total`
  - tie-break: `netWorth`
- Extended results and export payload:
  - winner score
  - player score in summary
  - per-player score and score breakdown in leaderboard export
- Updated UI leaderboard rows:
  - display score and net worth together

## Why This Matters

Simformer-style training is about management quality, not only cash at one point in time. The new score model reflects:

- financial result
- liquidity
- contracts
- innovation
- execution tempo
- debt pressure

This gives a more educational ranking signal and a clearer explanation of why a company is leading.

## Technical Notes

`buildSimulationScore()` currently uses deterministic weights:

- financial and liquidity rewards
- contract and innovation rewards
- season-goal and recent sales execution rewards
- discipline bonus for positive tick profit
- debt penalty reduced by reputation resilience

The model is intentionally simple and testable so balancing can continue in later product sprints.
