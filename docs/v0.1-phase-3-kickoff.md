## 3) Definition of done (этап 3)

Этап 3 считается закрытым, когда:

1. persistence path устойчив к частичным сбоям записи/чтения;
2. reconnect/refresh сценарии не ломают room/player state;
3. есть базовая версия схемы и проверка входных payload;
4. собран подтверждённый backlog release-readiness для этапа 4.
