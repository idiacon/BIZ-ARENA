# Следующий UX-апгрейд: первый ход и панель преподавателя

## Цель

Снизить хаос в первые 5 минут занятия:

- ученик сразу понимает, что делать в первом ходе;
- преподаватель быстро видит, кто не вошел, кто не готов и кто застрял;
- Server panel подсказывает следующее действие преподавателя;
- команды без закупки, работников, сборки или заявки видны без ручного просмотра каждой компании.

## Когда начинать

После реального LAN-теста на двух устройствах:

1. `BizArena Server` на ПК преподавателя.
2. `/client` или `BizArena Client` на втором устройстве.
3. Ученик входит в комнату по QR/LAN-ссылке.
4. Преподаватель видит ученика в лобби.

Если LAN не проходит, сначала проверить отдельный роутер/точку доступа.

## UX-pass 1: вход ученика

Сделать вход ученика более управляемым:

- на `/client` показать короткий заголовок `Войти в комнату преподавателя`;
- рядом с полем кода комнаты объяснить, что код показывает преподаватель;
- после успешного входа показать состояние `Вы в комнате, нажмите Готов`;
- если имя уже занято, дать понятный текст: `Измените имя или войдите с тем же названием компании`;
- в lite mode не перегружать экран анимациями и тяжелыми панелями.

Acceptance criteria:

- ученик понимает экран без устного объяснения;
- ошибка повторного имени не выглядит как системная ошибка;
- после входа есть один очевидный следующий шаг: `Готов`;
- `/client` остается в `data-performance-mode="lite"`.

## UX-pass 2: первый ход ученика

Сделать первый игровой ход линейным маршрутом:

1. `Закупка` - купить комплектующие.
2. `Персонал` - нанять работника.
3. `Сборка` - собрать товар.
4. `Маркетинг` - выставить заявку.
5. `Завершить ход` - ждать расчета.

Улучшения:

- закрепить блок `Что делать сейчас` выше сложных таблиц;
- показывать одну главную кнопку следующего действия;
- рядом с каждым шагом показывать статус: `не начато`, `готово`, `требует внимания`;
- после первого расчета показать короткий разбор: прибыль, продажи, что улучшить.

Acceptance criteria:

- ученик может завершить первый ход без перехода по лишним вкладкам;
- у каждого шага есть понятный done/attention статус;
- после расчета ученик видит, почему результат хороший или плохой.

## UX-pass 3: панель преподавателя

Сделать Server panel рабочим пультом занятия:

- сверху показать `Следующее действие преподавателя`;
- в лобби: `Ждем X учеников`, `Y готовы`, `можно запускать / рано запускать`;
- во время хода: `Команды без закупки`, `без работников`, `без сборки`, `без заявки`;
- выделить список `Кому нужна помощь` и причину;
- добавить быстрые подсказки: `подойдите к команде`, `можно делать разбор`, `можно считать ход`.

Acceptance criteria:

- преподаватель за 10 секунд понимает, можно ли запускать/считать ход;
- команды с блокерами видны без открытия карточек игроков;
- панель не предлагает Cloudflare;
- Network Doctor остается доступен, но не мешает игровому управлению.

## Технический контур

Основные файлы:

- `public/app.js` - UI flow ученика, Server panel, teacher panel;
- `public/styles.css` - compact/lite layout and teacher readiness styling;
- `server.js` и `server/factory/summary.js` - read models для подсказок и readiness;
- `test/stabilization.test.js` - regression checks для UI/source contracts;
- `scripts/smoke-classroom-lan.js` - classroom smoke after changes.

Проверки после UX-pass:

```powershell
npm run check
npm test
npm run smoke:classroom
```

Если правки затронут visual layout, дополнительно открыть:

- `http://127.0.0.1:3000/server`;
- `http://127.0.0.1:3000/client`;
- мобильный viewport для `/client`.

## Статус 2026-06-12

UX-pass 3 частично реализован как in-game teacher cockpit:

- `/server` остается стартовым экраном и сетевым центром.
- В игре добавлена заметная вкладка `Преподаватель` для хоста.
- Вкладка показывает `Что сделать сейчас`, кто вошел/готов, блокеры первого хода: без закупки, без работников, без сборки, без заявки.
- Вкладка дает кнопки `Запустить`, `Следующий ход`, `Пауза`, `Продолжить`, `Завершить`.
- Server action `finish-room` завершает матч из панели преподавателя с причиной `teacher_stopped`.
- Проверено: `npm run check`, `npm test`, `npm run smoke:classroom`, `npm audit --omit=dev`, Browser QA на `http://127.0.0.1:3221/`.
