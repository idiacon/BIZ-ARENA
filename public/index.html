About

Project

Educational business simulator for local classroom and championship-style demonstrations.

Current build

Version v1.0.0-beta.1 delivers the classroom pilot with a preflight gate, a focused teacher cockpit, one student next action, session history, and verified reconnect.

Game cycle

The player chooses purchasing, staffing, assembly, pricing, and sales decisions, then sees the result after turn resolution.

Championship flow

The demo follows a KAI-style cycle: register a company, make production decisions, resolve a turn, and compare the rating.

Learning focus

The player practices demand, price, components, payroll, contracts, debt, and result analysis.

Delivery package

The June package includes a Windows build, presentation, explanatory note, demo script, and optional GitHub repository.
